Frequently Asked Questions

What is Vinyasa AI?

Vinyasa AI is a powerful, web-based tool designed to help you create professional infographics instantly. It combines a wide range of templates with AI-powered content and image generation, all controlled through an easy-to-use, interactive interface.

Do I need to install any software?

No. Vinyasa AI is a fully browser-based application. There is nothing to install. Just open the `creator.html` file in a modern web browser like Chrome or Firefox to get started.

Do I need an API key to use this?

For the core infographic design and layout features, you do not need any API key. However, to use the AI-powered "AV Magic Studio" (for text generation) and "AV Image Studio," you will need to provide your own API keys from providers like OpenRouter or Google AI Studio. The tool has a settings panel to enter these keys securely.

Is this tool suitable for creating content in Kannada?

Absolutely! Vinyasa AI was built with Kannada creators in mind. It uses the 'Anek Kannada' font for beautiful rendering, and the AI prompt templates are specifically designed to request and handle Kannada-language content from the AI models.

Can I save my work?

Yes. The tool includes a "Save" button that stores all your settings and input text in your browser's local storage. When you return, your last-used configuration will be loaded automatically. You can also download your final creation as a high-quality JPG or PNG image.

Are my API keys and data secure?

Your API keys are stored only in your browser's local storage and are never sent to any server other than the AI provider you select (e.g., OpenRouter, Google). The entire application runs locally on your computer. Your data and keys are as secure as your own machine.

What infographic types are available?

Vinyasa AI offers a wide range of types, including Dashboards, Social Posts, News Alerts, Process Flows, Timelines, various Charts (Bar, Pie, Doughnut, Gauge), Dam Levels, Price cards, Comparison tables, Hierarchies, Lists, and "Did You Know?" facts.

Can I use my own images?

Yes. Most templates that use images have fields for both pasting an image URL and uploading an image directly from your computer. Uploading is recommended for best results and to avoid potential cross-origin (CORS) issues.

Is there a dark mode?

Yes! The application features a beautiful dark mode that can be toggled in the sidebar. This affects both the editor interface and the default colors available for your infographics, ensuring a comfortable creative experience day or night.

Who created Vinyasa AI?

Vinyasa AI is a creative passion project developed by Avinash Vagarnal, designed to empower creators to tell their stories visually without the steep learning curve of traditional design software.
